# Dra. Sofía Mendoza — Landing de pediatría

Landing page para portafolio: Vite + HTML/CSS/JS vanilla, diseño aireado y animaciones suaves al estilo Apple.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre la URL que muestra Vite (normalmente `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Personalizar

Edita textos y datos de contacto en `index.html` (o usa `contenido.md` como referencia). Sustituye imágenes en `public/images/`.

## Despliegue

Conecta el repositorio a [Vercel](https://vercel.com). Preset: Vite.
